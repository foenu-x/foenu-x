# Foenu-x v26.10.10

Свой язык программирования. Интерпретатор на Python, синтаксис в стиле Pascal (`begin`/`end`), текст в `#скобках#`, запуск команд оболочки через `CMD(...)`.

- Расширение файлов: **`.foenu-x`**
- Версия: **26.10.10** (номер по дате релиза)
- Статус: **БЕТА**

## Запуск

```powershell
cd "Python Проекты\foenu-x"

python main.py examples\hello.foenu-x   # выполнить файл
python main.py                          # REPL (для выхода: exit)
```

Нужен Python 3.8+. Дополнительных библиотек нет.

## Пример

```pascal
// числа.foenu-x
var числа be [3, 1, 4, 1, 5];
var сумма be 0;

for i := 0 to len(числа) - 1 begin
  сумма := сумма + числа[i];
end;

Foenu-x text-(#Сумма: #) + сумма;
if сумма % 2 = 0 then begin
  Foenu-x text-(#Чётная#);
end;
```

## Синтаксис

| Конструкция | Запись |
|---|---|
| Комментарий | `// текст` |
| Текст | `#любой текст#` |
| Вывод | `Foenu-x выражение;` |
| В текст | `text-(выражение)` |
| Переменная | `var имя be значение;` |
| Присваивание | `имя := значение;` |
| Массив | `var a be [1, 2, 3];` |
| Элемент | `a[0]` (счёт с нуля) |
| Изменить элемент | `a[0] := 5;` |
| Условие | `if ... then begin ... end else begin ... end;` |
| Цикл | `while условие begin ... end;` |
| Цикл со счётчиком | `for i := 1 to 5 begin ... end;` |
| Обратный счёт | `for i := 5 downto 1 begin ... end;` |
| Выход из цикла | `break;` / `continue;` |
| Функция | `function имя(арг) begin ... end;` |
| Возврат | `return значение;` |
| Команда ОС | `CMD(#команда#);` |
| Ввод | `input(#приглашение#)` |
| Логика | `and`, `or`, `not`, `true`, `false` |
| Операторы | `+ - * / %`, `= == !=`, `> < >= <=` |

## Встроенные функции

| Функция | Что делает |
|---|---|
| `len(x)` | длина текста или массива |
| `push(массив, элемент)` | добавить элемент в конец |
| `pop(массив)` | убрать и вернуть последний элемент |
| `upper(#abc#)` / `lower(#ABC#)` | регистр текста |
| `abs(x)`, `min(a, b)`, `max(a, b)` | математика |
| `random(1, 10)` | случайное целое от 1 до 10 |
| `num(#42#)` | текст → число |
| `input(#...#)` | прочитать строку с клавиатуры |

## Обучающий корпус (для нейросети)

`data/foenu-x-corpus.md` — сгенерированный корпус ~40 МБ: статьи, справочники,
тысячи вопросов-ответов, типичные ошибки и тысячи примеров кода.
Каждый пример реально выполнен интерпретатором, поэтому вывод корректен.

```powershell
python tools\generate_corpus.py      # перегенерировать 40 МБ
python tools\generate_corpus.py 0.5  # тестовый прогон
```

Документация на HTML: `docs/index.html` (и `HTML Страницы/foenu-x/index.html`).
