Foenu-x

Свой язык программирования: Pascal-стиль, текст в #скобках#, запуск команд CMD

расширение .foenu-x интерпретатор на Python синтаксис begin / end версия 1.0

01Быстрый старт

Записи файл с расширением .foenu-x и запусти:

> python main.py examples\hello.foenu-x

Или открой REPL (просто python main.py) и печатай команды построчно.

// hello.foenu-x
Foenu-x text-(#Hello, World!#);

02Вывод

Foenu-x печатает выражение, text-(...) превращает его в текст, #...# — литерал текста.

Foenu-x 42;
Foenu-x text-(#Число: ) + 42;
Foenu-x text-(#Привет, ) + имя + text-(#!);

03Переменные

Объявление через var ... be, переприсваивание через :=. Типы не указываются — переменная сама хранит число или текст.

var имя be #Foenu-x#;
var число be 10;

имя := #Мир#;
число := число + 1;

04Условия и циклы

if число > 5 then begin
  Foenu-x text-(#Больше#);
end else begin
  Foenu-x text-(#Меньше#);
end;
var счётчик be 3;
while счётчик > 0 begin
  Foenu-x счётчик;
  счётчик := счётчик - 1;
end;

05Функции

Объявление function, возврат через return. Поддерживается рекурсия.

function факториал(n) begin
  if n <= 1 then begin
    return 1;
  end;
  return n * факториал(n - 1);
end;

Foenu-x факториал(5);   // 120

06Команды системы (CMD)

CMD(#...#) выполняет команду оболочки (cmd / PowerShell) и печатает её вывод.

CMD(#echo Hello from CMD#);
CMD(#dir#);
CMD(#powershell -Command "Get-Date"#);
