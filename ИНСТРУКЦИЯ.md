# Инструкция для тебя — язык Foenu-x

Простая памятка: как писать, запускать и смотреть программы на своём языке.

---

## 1. Первая программа за 30 секунд

1. Открой папку `Python Проекты\foenu-x` в проводнике.
2. В адресной строке набери `cmd` и нажми Enter (откроется чёрное окно).
3. Напиши и запусти:

```
python main.py examples\hello.foenu-x
```

Увидишь:

```
Hello, World!
Привет из Foenu-x!
```

Любой другой пример запускается так же — подставь имя файла.

## 2. REPL — командная строка (как в Python)

Запусти без файла:

```
python main.py
```

Появится шапка и приглашение `>>>`. Печатай команды по одной:

```
>>> var x be 5;
>>> Foenu-x x * 2;
10
>>> 2 + 3
5
```

Выражения сами печатают результат (как в Python). Если ввёл `begin` и нажал
Enter — строка продолжится `... ` пока не допишешь `end`.

Команды оболочки:
- `help` — справка
- `version` — версия
- `clear` — очистить экран
- `exit` — выход

## 3. Справочник языка (всего 12 правил)

| Что нужно | Как писать |
|---|---|
| Комментарий | `// это комментарий` |
| Текст | `#привет мир#` |
| Вывод | `Foenu-x значение;` |
| Текст из числа | `text-(5)` → `"5"` |
| Переменная | `var имя be 5;` |
| Переприсвоить | `имя := 10;` |
| Условие | `if x > 3 then begin ... end else begin ... end;` |
| Цикл | `while x > 0 begin ... end;` |
| Функция | `function f(a) begin return a * 2; end;` |
| Вызвать | `f(21);` |
| Команда Windows | `CMD(#dir#);` |
| Логика | `and`, `or`, `not`, `true`, `false` |

Операторы: `+ - * /` (деление: `10 / 4` = `2.5`, `10 / 2` = `5`),
сравнение `= == != > < >= <=`, приоритет как в математике.

Полный пример со всеми конструкциями — `examples\test_all.foenu-x`.

## 5. VS Code — цвета и удобство

Расширение уже установлено. После обновления VS Code (Ctrl+Shift+P →
"Reload Window") файлы `.foenu-x` открываются как язык Foenu-x:
цветные ключевые слова, автозакрытие `#` и скобок, отступы по begin/end.

Двойной клик по `.foenu-x` в проводнике → открывается VS Code.

## 6. Красивый HTML из любого файла

```
python tools\highlight.py examples\hello.foenu-x
```

Рядом появится `hello.html` — открой в браузере, код будет цветной.

## 7. DeepSeek пишет за тебя код

1. Открой `инструкция-deepseek.txt`, скопируй текст между маркерами
   «НАЧАЛО/КОНЕЦ ТЕКСТА ДЛЯ ВСТАВКИ».
2. Вставь в новый чат DeepSeek.
3. Проси: «напиши игру угадай число на Foenu-x».
4. Получишь код + цветной HTML. Код сохрани в файл `.foenu-x` и запусти
   через `python main.py`. Цветной HTML сохрани как `.html` → браузер.

Если ИИ где-то ошибся — покажи ему ошибку из консоли, он поправит.

## 9. Частые ошибки

| Сообщение | Что делать |
|---|---|
| `python не является внутренней...` | Установи Python 3 (галочка "Add to PATH") |
| `переменная 'x' не объявлена` | Сначала `var x be ...;` |
| `уже объявлена` | Переменная повторно объявлена — убери лишний `var` |
| `деление на ноль` | Проверь делитель |
| `не хватает end` | Закрой каждый `begin` парным `end` |
| `незакрытый текстовый литерал` | Закрой текст вторым `#` на той же строке |
| Кириллица кракозябрами | Сохраняй файл в UTF-8 |
| Цветов в VS Code нет | Ctrl+Shift+P → "Reload Window", проверь расширение Foenu-x |
