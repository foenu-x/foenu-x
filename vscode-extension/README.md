# Расширение Foenu-x для VS Code

Подсветка синтаксиса и режим языка **Foenu-x** для файлов `.foenu-x`.

## Что даёт

- Файлы `.foenu-x` открываются как **Foenu-x** (не как Python/текст)
- Цвета: ключевые слова, текст `#...#`, числа, комментарии, функции, операторы
- Автозакрытие `#` и скобок, отступы по `begin`/`end`, комментарий `//`

## Установка (уже выполнена скриптом проекта)

Расширение копируется в `%USERPROFILE%\.vscode\extensions\foenu-x.foenu-x-1.0.0`,
после чего VS Code перезагружается (Ctrl+Shift+P → "Reload Window").

Проверка: открой любой `.foenu-x` — внизу справа в статус-баре должно быть "Foenu-x".
